# BMZ Trend Focus

> Central de planejamento, geração, agendamento e análise de conteúdo para redes sociais.

O **BMZ Trend Focus** é uma plataforma full-stack para gestão de conteúdo em múltiplos canais, incluindo Instagram, TikTok, LinkedIn, YouTube e Facebook.

A aplicação centraliza criação assistida por IA, calendário editorial, biblioteca de ativos, gestão de contas e análise de performance.

---

## Funcionalidades

### Dashboard

* Visão consolidada de alcance, engajamento e publicações agendadas
* Próximos posts por rede social e status
* Acesso rápido à criação de conteúdo

### Estúdio de Conteúdo com IA

* Geração de roteiros, legendas, carrosséis, threads e artigos
* Ajuste de tom de voz
* Salvamento como rascunho ou agendamento direto

### Calendário Editorial

* Visualização mensal das publicações
* Identificação por rede social e status
* Consulta dos conteúdos programados por data

### Biblioteca de Conteúdo

* Armazenamento de hooks, copys, hashtags e roteiros
* Organização e reutilização por categoria

### Relatórios

* Comparação de alcance entre plataformas
* Análise de impressões e interações
* Identificação dos conteúdos com melhor desempenho

### Gestão de Contas

* Gerenciamento de perfis sociais conectados
* Controle dos canais ativos e integrações

### Segurança

* Autenticação por e-mail/senha e Google OAuth
* Isolamento de dados com Row Level Security (RLS)
* Ambiente demo com dados pré-configurados

## Stack

* **Frontend:** TanStack Start v1, React 19
* **Roteamento:** TanStack Router
* **Data Fetching:** TanStack Query
* **Estilização:** Tailwind CSS v4
* **Banco de Dados:** PostgreSQL
* **Backend:** Lovable Cloud
* **Autenticação e Segurança:** Auth + RLS
* **Storage:** Lovable Cloud Storage
* **IA:** AI SDK e modelos generativos
* **UI:** Lucide React e Sonner

## Executar Localmente

### Requisitos

* Node.js 20+ ou Bun
* npm, pnpm ou bun

### Instalação

```bash
git clone https://github.com/seu-usuario/bmz-trend-focus.git
cd bmz-trend-focus
```

Instale as dependências:

```bash
npm install
```

Execute o ambiente local:

```bash
npm run dev
```
